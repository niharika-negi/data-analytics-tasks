# Module I – Data Analytics Practice & Revision

## 1. Data Analytics

Data Analytics is the process of collecting, cleaning,
transforming and analyzing data to discover useful
information, patterns and trends.

It helps organizations make data-driven decisions.

---

## 2. Importance of Data Analytics

Data Analytics helps organizations to:

- Make better decisions
- Identify trends and patterns
- Understand customers
- Improve business performance
- Reduce costs
- Identify problems
- Find new opportunities

---

## 3. Applications of Data Analytics

Data Analytics is used in many areas:

- E-commerce
- Banking and Finance
- Healthcare
- Marketing
- Education
- Retail
- Human Resources

### Example

An e-commerce company can analyze sales data to find:

- Best-selling products
- Monthly sales trends
- Customer purchasing behaviour
- Region-wise sales
- Low-performing products

---

## 4. Data Analytics vs Data Science

| Data Analytics | Data Science |
|---|---|
| Focuses on analyzing existing data | Uses data to solve complex problems |
| Finds trends and patterns | Builds predictive models |
| Uses Excel, SQL, Power BI etc. | Uses Python, ML, statistics etc. |
| Supports business decisions | Can create predictive systems |

---

## 5. Types of Data Analytics

### Descriptive Analytics

Answers:

**What happened?**

Example:
Total sales were ₹5,00,000 last month.

### Diagnostic Analytics

Answers:

**Why did it happen?**

Example:
Sales decreased because of lower sales in one region.

### Predictive Analytics

Answers:

**What may happen?**

Example:
Sales may increase next month based on previous trends.

### Prescriptive Analytics

Answers:

**What should we do?**

Example:
The company should increase marketing for low-performing products.

---

## 6. Data Analytics Lifecycle

A simple Data Analytics lifecycle is:

**Capture → Clean → Analyze → Visualize → Report**

### Capture

Collect data from different sources.

### Clean

Remove errors, duplicates and inconsistent values.

### Analyze

Find patterns, trends and relationships.

### Visualize

Represent data using charts, graphs and dashboards.

### Report

Communicate findings and insights.

# Practice Questions

## Short Answer Questions

### Q1. What is Data Analytics?

Data Analytics is the process of examining data to find
useful information, patterns and trends that help in
decision-making.

### Q2. What is Descriptive Analytics?

Descriptive Analytics explains what happened in the past
using historical data.

### Q3. What is Diagnostic Analytics?

Diagnostic Analytics helps identify why something happened.

### Q4. What is Predictive Analytics?

Predictive Analytics uses existing data and patterns to
estimate what may happen in the future.

### Q5. What is Prescriptive Analytics?

Prescriptive Analytics suggests possible actions based on
data and analysis.

### Q6. Name five Data Analytics tools.

- Excel
- SQL
- Power BI
- Python
- Tableau

# Scenario-Based Practice

## Scenario

An online shopping company has noticed that its sales have
decreased during the last three months.

The company has customer, product, sales, date and region data.

### Questions

1. What type of analytics can be used to find what happened?
2. Which type can help identify the reason for the decrease?
3. Which type can estimate future sales?
4. Which type can suggest possible actions?
5. Which tools can be used to analyze the data?

### Expected Approach

1. Descriptive Analytics → Find what happened
2. Diagnostic Analytics → Find the possible reasons
3. Predictive Analytics → Estimate future sales
4. Prescriptive Analytics → Suggest possible actions
5. Excel / SQL / Power BI / Python → Depending on the task
