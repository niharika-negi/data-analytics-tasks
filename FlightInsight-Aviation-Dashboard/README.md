# ✈️ FlightInsight — Aviation Analytics Dashboard

An interactive aviation analytics dashboard developed using Microsoft Power BI to explore flight activity, delay patterns, and airline performance.

## 📊 Dashboard Preview

The dashboard provides a visual overview of flight performance and delay trends.

## ✨ Key Features

* Total Flights and Delayed Flights KPIs
* Flight Delay Rate Analysis
* Flight Trends Over Time
* Top Airlines by Delayed Flights
* Top Airports by Delayed Flights
* Delay Analysis by Cause and Month
* Route Analysis and Airport Map

## 🛠️ Tools Used

* Microsoft Power BI
* DAX
* Data Visualization
* Data Analysis

## 🎯 Project Objective

To transform flight data into meaningful insights using interactive visualizations and KPI metrics.

## 📚 Learning Outcomes

Practiced KPI creation, DAX measures, dashboard design, and data storytelling.
